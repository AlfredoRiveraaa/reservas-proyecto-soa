# ReservaSOA — Plataforma de Reservación de Espacios con Arquitectura SOA

Proyecto final de la materia **Cómputo Orientado a Servicios**.

## Descripción
Sistema distribuido orientado a servicios (SOA) para la gestión de usuarios, espacios/recursos corporativos, reservaciones orquestadas y confirmaciones.
